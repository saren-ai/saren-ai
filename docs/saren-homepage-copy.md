### Build notes (for Claude Code / not on page)

- **Cut entirely from the live site:** the three interactive tools, the four "Coming Soon" downloads, the four-card case-study grid, the FAQ, the GTM-Engineer hero. All of it was making a visitor work before they'd decided anything.
- **"Coming Soon" ban:** don't ship a section labeled "Coming Soon." It reads *unfinished*. Hide until live.
- **One CTA, repeated.** "Let's talk" top and bottom, same words both times. No competing buttons.
- **Pillars are scannable units** — eyebrow + one sentence + one italic "so what." Don't let them grow back into paragraphs.
- **Case studies / playbooks / tools** still exist — move them to their own pages, one click deep. The homepage points; it doesn't contain.
