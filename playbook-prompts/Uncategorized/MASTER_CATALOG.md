## Database Import Notes

The machine-readable version of this catalog lives in `prompt_catalog.json`. Here's the schema summary for your dev team:

### `playbooks[]`
```
playbook_id    string   — kebab-case unique ID
title          string   — display name
description    string   — 1-2 sentence summary
category       string   — primary category (Marketing, Copywriting, etc.)
tags           string[] — searchable tag array
status         enum     — "active" | "archived"
steps[]        object[] — ordered array of steps
  step         number   — step number (0-indexed for Sora series)
  title        string   — step display name
  file         string   — relative path to prompt .md file
  note         string?  — optional flag (e.g., missing step, multi-prompt file)
```

### `prompts.active[]` / `prompts.archived[]`
```
id             string   — kebab-case unique ID
title          string   — display name
file           string   — relative path to .md file
category       string[] — one or more categories
tags           string[] — searchable tags
date           string   — ISO date (YYYY-MM-DD)
series_id      string?  — links to parent playbook_id if part of a series
series_step    number?  — step number within the series
```

### Recommended DB tables
- `playbooks` — one row per playbook
- `playbook_steps` — one row per step (FK: playbook_id)
- `prompts` — one row per prompt
- `prompt_tags` — many-to-many join table (prompt_id × tag)
- `prompt_categories` — many-to-many join (prompt_id × category)
