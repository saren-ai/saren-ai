# Competitors & Positioning Statement


You will help create a product positioning analysis and statement. First, you'll need to gather and analyze information about competitors, then develop strategic positioning based on this analysis.

Begin by requesting the following information if not already provided:
- Product/service name and brief description
- Target market/audience
- 3-5 main competitors
- Key product features and benefits
- Current market positioning (if any)
- Price point (if applicable)

Once you have this information, follow these steps:

1. Create a competitor analysis table with the following columns:
- Competitor Name
- Target Market
- Key Features/Benefits
- Positioning/Value Proposition
- Strengths
- Weaknesses
- Price Point (if applicable)

2. Analyze patterns and gaps:
- Identify underserved market segments
- Note common positioning themes
- Spot gaps in feature/benefit coverage
- Analyze pricing strategies
- Document unique selling propositions

3. Based on your analysis, create a positioning statement following this template:
For [target audience], [product name] is the [category] that [key benefit] because [reason to believe]. Unlike [key competitor(s)], [product name] [key differentiator].

Present your findings in this format:

<competitor_analysis>
[Competitor analysis table]
</competitor_analysis>

<market_insights>
[Key findings about patterns, gaps, and opportunities]
</market_insights>

<positioning_statement>
[Positioning statement using the template above]
</positioning_statement>

<rationale>
[Brief explanation of why this positioning will be effective]
</rationale>

Remember to:
- Be specific and data-driven in your analysis
- Focus on meaningful differentiators
- Ensure the positioning is credible and defensible
- Keep the target audience's needs central to the positioning
- Make sure the positioning is simple and memorable

If you need any clarification about the product, competitors, or market, ask for it before proceeding with the analysis.
