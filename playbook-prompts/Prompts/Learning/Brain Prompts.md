# Brain Prompts


It takes most people months to learn something new.
I use these 10 ChatGPT prompts to do it in days.

## 1. Focus Block Designer

Prompt: "Create 90-minute deep work sessions for [Topic]. Break them down into 25-minute chunks with specific deliverables. Add clear success cues and blocks for distractions. Include this in a daily schedule with energy scores. Topic: [Your Topic].
Peak Times: [Best Times]."

## 2. Active Recovery Builder

Prompt: "Design a multiple-choice learning sequence for [Subject]. Start with problems before learning the concepts. Include self-assessment points and attempted solutions. Display it on a practice sheet with scaling difficulty. Subject:
[Your Subject]."

## 3. Pattern Recognition Accelerator

Prompt: "Find common patterns in the foundations of [Topic]. Connect each pattern to everyday examples and prior knowledge.
Add application exercises. Present it in a connection map with practical scenarios.
Topic: [Your Topic]."

## 4. Mental Model Creator

Prompt: "Map the key principles of [Topic] onto simple frameworks. Create decision trees and problem-solving guides. Add real-world applications. Present it in a cheat sheet with usage examples. Topic: [Your Topic]."

## 5. Intercalated Practice Designer

Prompt: "Mix up different aspects of [Skill] in each practice session. Create varied challenge sets with increasing complexity. Add feedback points. Display on a practice grid with a mastery track. Skill: [Your Skill]."

## 6. Knowledge Segmentation Guide

Prompt: "Break [Complex Topic] into smaller, connected pieces. Design 5-minute learning sessions for each segment. Include bridging concepts. Present it in a learning map with sequence indicators. Topic: [Your Topic]."

## 7. Elaborative Processing Builder

Prompt: "Create explanation challenges for [Subject]. Design moments to teach the content and connect concepts. Add why and how questions. Present it in practice format with understanding checkpoints.
Subject: [Your Subject]."

## 8. State Change Maximizer

Prompt: "Design learning modes based on different energy levels in [Topic]. Create high-focus activities and review modes.
Add exercises specific to each state.
Present on a schedule tailored to your energy level. Topic: [Your Topic]."

## 9. Feedback Loop Accelerator

Prompt: "Build a rapid testing system to develop [Skill]. Create quick checks and adjustment points. Include improvement triggers. Display it in a progress tracker with velocity indicators. Skill: [Your Skill]."

## 10. Recovery Practice Optimizer

Prompt: "Design spaced recovery sessions to master [Topic]. Create practice sets with increasing intervals. Add difficulty progression.
Present it in a review calendar with strength markers. Topic: [Your Topic]."
