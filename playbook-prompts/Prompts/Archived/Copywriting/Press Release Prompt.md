# Press Release Prompt


Here is an outline for a press release announcing new features and functionalities for your Wethos Copilot product:
Headline:
Wethos Unveils Major Upgrade to Copilot Psychometric and Team Dynamics Tool
Subheadline:
New features enhance personality insights, team building, and productivity for modern workforces
Introduction (2-3 sentences):

Briefly introduce Wethos and Copilot - what it is and what needs it serves
Mention this is a major new release with significant upgrades
Can tease a high-level overview of one or two top new features

About the New Release (3-5 paragraphs):

Overview paragraph on the goals/vision behind this new release
2-4 paragraphs going over key new features and capabilities in more detail

Describe what each one is and the benefits it provides
Could include any new assessment types, team analytics, integration capabilities, etc.


If applicable, a paragraph on UI/UX improvements

Customer Quotes (1-2 brief quotes):

Include 1-2 quotes from customers/users giving positive feedback on the new tools

Additional Product Details (1 paragraph):

Rundown of pricing/packaging options
Reiterate core use cases
Highlight awards/market leadership if applicable

About Wethos (1 paragraph):

Brief boilerplate overview of the company and its mission

Call-to-Action:

Invite people to sign up for a free trial or demo
Link to product website

Contact Information:

Provide press contact details for any follow-ups

The key is to make the release engaging and highlight the key new capabilities that solve problems for your users. Use plain language, compelling customer anecdotes, and focus on core benefits over heavy technical details. I'm happy to provide any other guidance as you draft the actual release.
